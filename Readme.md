# Untangle

A simple web-game about untangling lines.

## How to play

1. Open the [GitHub Pages Deployment](https://mich101mich.github.io/untangle/)

1. You will find an initial state that looks something like this:

   ![untangle game with two crossed lines that are red](docs\crossed-line.png)

   Note that lines that cross other lines are colored red, while uncrossed lines are green.

1. The goal of the game is to make all lines green:

   ![untangle game with no crossed lines](docs\solved-state.png)

   This can be achieved by dragging the dots until no lines are crossing each other.\
   Note that points can't overlap with each other either.

1. And that's it!

   Solving a level will advance you to the next level, with the game getting progressively more difficult as you advance.
